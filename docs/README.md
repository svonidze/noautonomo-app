# Documentation

Start with [Local setup](../SETUP.md) to install and run the application.
Read the [experimental-use terms](../TERMS.md) for permitted use and responsibility.

User guidance is in [user/](user/): the accounting workflow, statuses, account
settings, counterparty corrections, VIES checks, exchange rates, history replay,
the [Renta WEB draft review checklist](user/RENTA_DRAFT_CHECKLIST.md), the
[RETA bracket check](user/RETA_CHECK.md), and the
[official references](user/OFFICIAL_REFERENCES.md) behind the interface term
tooltips.
Developer guidance is in [development/](development/): frontend development,
localization, privacy, and the repository layout. Operational runbooks live in
[ops/docs/](../ops/docs/), including deployment, provisioning, frontend build,
and disaster recovery. [plans/](plans/) records historical proposals and
implementation decisions for the product and its code; it is not an operating
manual. Plans about an operator's own tax affairs, filings or accounting
records stay in private storage outside this repository and are not referenced
from it. Plan files are named `YYYY-MM-DD-topic.md` by the date the plan was
first written, not the date it was committed.

The repository's shared examples are in [examples/](../examples/) and the
official calendar input is [reference/tax-calendars/2026.json](../reference/tax-calendars/2026.json).

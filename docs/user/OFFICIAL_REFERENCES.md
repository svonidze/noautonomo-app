# Official references

The interface term tooltips name these sources without their addresses.

- [AEAT IRPF practical manuals](https://sede.agenciatributaria.gob.es/Sede/manuales/irpf_.html): how personal income tax treats an asset purchase and its depreciation.
- [AEAT place-of-supply locator for services](https://www2.agenciatributaria.gob.es/wlpl/AVAC-CALC/LocalizadoresServicios): where a service is taxed for IVA.
- [AEAT place-of-supply locator for goods](https://www2.agenciatributaria.gob.es/wlpl/AVAC-CALC/LocalizadoresBienes): where a supply of goods is taxed for IVA.
- [VIES VAT number validation](https://ec.europa.eu/taxation_customs/vies/#/vat-validation): whether an EU VAT number is valid for intra-Community operations; see [VIES checks](VIES_CHECK.md).
